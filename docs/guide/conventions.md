# 阅读约定

## 数值与单位

- 十六进制数写作 `0x` 前缀，例如 `0x1000F000`；二进制数写作 `0b` 前缀。
- 1 KB = 1024 字节，1 MB = 1024 KB。
- 数据宽度：字节（byte）8 位，半字（halfword）16 位，字（word）32 位，双字（doubleword）64 位，四字（quadword，简称 QW）128 位。
- 位编号从 0 开始，第 0 位为最低有效位（LSB）。位域写作 `高位:低位`，例如 `7:4`。

## 地址

- EE 寄存器地址一律写**物理地址**。程序通常经 KSEG1（`物理地址 + 0xA0000000`，不经缓存）访问，例如 I_STAT 的物理地址为 `0x1000F000`，程序中写作 `0xB000F000`。
- IOP 寄存器地址写 IOP 物理地址，例如 `0x1F801070`。
- 经 SBUS 窗口从 EE 访问 IOP 资源时，在文中注明两侧地址。
- 没有总线地址的寄存器（CP0 寄存器、GS 一般寄存器、VU 寄存器等）写寄存器编号。

## 寄存器属性

| 缩写 | 含义 |
|---|---|
| R/W | 可读可写 |
| RO | 只读，写入无效 |
| WO | 只写，读出值无意义 |
| R/W1C | 可读；写 1 清零对应位，写 0 无影响 |
| R/W1T | 可读；写 1 翻转对应位，写 0 无影响 |
| R/C | 读出后自动清零 |

## 寄存器说明的格式

每个寄存器块先给出汇总表，然后逐个寄存器给出：

1. 头部表格：地址、位宽、属性、复位值、可信度；
2. 功能说明；
3. 位域图：最高位在左，灰色区域为保留位；
4. 位域说明表：位、名称、属性、复位值、说明，必要时附取值表；
5. 典型操作步骤与注意事项；
6. 来源。

除非另有说明，保留位读出值不确定，写入时应写 0，或按“读—改—写”方式保持原值。

只有正文中引用到的表格才带“表 N-n”编号，其余表格不编号。
